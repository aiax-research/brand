# AIAX Lab Brand Assets
대진대학교 AIAX Lab의 로고와 디자인 파일을 저장하는 저장소입니다.  
발표 자료, 포스터, 논문 그림에 연구실 로고가 필요한 경우 여기서 다운로드하여 사용하여 주십시오.

### 폴더 구조
```
.
└─ logo
   ├─ symbol        심볼 전용 버전
   ├─ wordmark      글자 전용 버전
   └─ lockup        심볼 + 글자 조합 버전 (권장)
```

### 사용법
화면 : 높이 25px 이상  
인쇄 : 높이 10mm 이상  

밝은 배경 > color 또는 black 버전  
어두운 배경 > white 버전

여백
로고 주변에는 심볼 높이의 절반 이상을 비워야 합니다.  
다른 기관 로고와 나란히 사용할 때에도 이 간격을 지켜주시길 바랍니다.

### 사용 금지 조항
- 가로, 세로 비율을 바꿔서 늘리거나 줄이기
- 로고 색을 임의로 변경
- 그림자, 외곽선, 그라데이션 같은 효과 사용
- 심볼과 글자의 간격이나 배치 변경
- 캡쳐한 저해상도 이미지 사용

### 파일 이름 규칙
'aiax_[type]_[version]_[color]'  
example : aiax_logo_symbol_white.png
